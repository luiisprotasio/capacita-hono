MÓDULO 04 · CONTRATOS OPENAPI

O arquivo .routes.ts

Descreva operações HTTP com createRoute: caminho, método, parâmetros, body e respostas.

Descrever sem executar

Em artigo.routes.ts, importe schemas e declare o contrato OpenAPI. Use a sintaxe OpenAPI {id} no caminho.

export const updateStatusRoute = createRoute({
  method: 'patch', path: '/{id}/status',
  tags: ['Artigos'], summary: 'Atualiza o status',
  request: {
    params: ArtigoParamsSchema,
    body: { content: { 'application/json': {
      schema: UpdateStatusSchema,
    } } },
  },
  responses: {
    200: { description: 'Status atualizado', content: {
      'application/json': { schema: ArtigoResponseSchema },
    } },
    404: { description: 'Artigo não encontrado' },
  },
});

O que o contrato responde

  • Qual método e caminho o cliente chama?
  • Quais entradas serão validadas?
  • Quais respostas e códigos HTTP podem ocorrer?

Não coloque handler, consulta ao banco ou regra de negócio neste arquivo.
