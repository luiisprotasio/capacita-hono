MÓDULO 06 · HANDLER HTTP

O arquivo .router.ts

Conecte o contrato ao handler, obtenha valores validados e traduza o resultado do service em respostas HTTP.

Conectar contrato e execução

O router instancia OpenAPIHono e registra handlers com router.openapi().

artigoRouter.openapi(updateStatusRoute, async (c) => {
  const { id } = c.req.valid('param');
  const { status } = c.req.valid('json');
  const artigo = await artigoService.updateStatus(id, status);
  if (!artigo) return c.json({
    status: 'error', message: 'Artigo não encontrado',
  }, 404);
  return c.json(artigo, 200);
});

Fluxo da requisição

ETAPA

1 · Contrato

router.openapi associa a rota de artigo.routes.ts ao callback que executa a operação.

router.openapi(updateStatusRoute, handler)

Não redefina schemas nem consulte Prisma aqui. Use c.req.valid() e deixe o acesso a dados no service.
