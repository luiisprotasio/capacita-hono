MÓDULO 03 · SCHEMAS

O arquivo .schema.ts

Defina formatos de entrada e saída do módulo, validações, metadados OpenAPI e tipos inferidos.

O que pertence ao schema

Em artigo.schema.ts, concentre schemas de parâmetros, body e respostas usados pelo recurso.

import { z } from '@hono/zod-openapi';

export const ArtigoParamsSchema = z.object({
  id: z.string().min(1).openapi({ example: 'art-123' }),
});
export const UpdateStatusSchema = z.object({
  status: z.enum(['rascunho', 'publicado']),
}).openapi('UpdateArtigoStatusInput');
export type UpdateStatusInput =
  z.infer<typeof UpdateStatusSchema>;

Schema de resposta

A resposta declara também campos produzidos pelo servidor, para que o contrato documente o que o cliente recebe.

export const ArtigoResponseSchema = z.object({
  id: z.string(), titulo: z.string(),
  status: z.enum(['rascunho', 'publicado']),
  criadoEm: z.string().datetime(),
}).openapi('ArtigoResponse');
export type ArtigoResponse =
  z.infer<typeof ArtigoResponseSchema>;

Não importe Prisma, não chame services e não crie OpenAPIHono. Defina contratos de dados e tipos derivados.
