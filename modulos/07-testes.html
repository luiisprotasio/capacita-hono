O arquivo .test.ts

Teste o endpoint atravessando roteamento, validação, handler e service sem iniciar servidor de rede.

Teste o contrato observável

Em artigo.test.ts, faça requisição contra app. Verifique status e body; não teste somente funções privadas do handler.

it('atualiza status do artigo', async () => {
  const response = await app.request(
    '/artigos/art-123/status',
    { method: 'PATCH',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ status: 'publicado' }) },
  );
  expect(response.status).toBe(200);
  expect(await response.json()).toMatchObject({
    id: 'art-123', status: 'publicado',
  });
});

Cubra sucesso e falhas

  • Sucesso: status atualizado e campos não alterados preservados.
  • Entrada inválida: schema rejeita valor fora do enum.
  • Artigo ausente: aplicação devolve 404 com mensagem clara.

Ao testar JSON, envie Content-Type: application/json; sem o header, o parser pode não interpretar o body.
