MÓDULO 05 · REGRA DE NEGÓCIO

O arquivo .service.ts

Implemente regras e acesso a dados sem acoplar a lógica ao contexto HTTP do Hono.

Uma função de domínio

O service recebe ID e status, localiza o artigo e devolve o registro atualizado. Retorna null quando não existe.

export const artigoService = {
  async updateStatus(
    id: string, status: ArtigoStatus,
  ): Promise<ArtigoResponse | null> {
    const artigo = await prisma.artigo.findUnique({ where: { id } });
    if (!artigo) return null;
    return prisma.artigo.update({
      where: { id }, data: { status },
    });
  },
};

Traduzir o resultado

O service expressa um resultado de domínio: artigo atualizado ou ausente. O router traduz ausência para HTTP 404 e sucesso para HTTP 200.

Se uma função exige o objeto c para funcionar, ela provavelmente conhece detalhes HTTP demais para ser uma regra do service.
